# 后四关技能音效

日期：2026-09-26。状态：四音效已生成并接入，确定性、格式、Godot 导入和运行解码检查通过；扬声器听感尚未验证。沿用[全游戏音频](audio.md)的总线、暂停、优先级和限流，不新增背景音乐或运行依赖。

新增四个原创合成音色：`enemy_whistle` 为两次柔和气哨，表达起跑；`enemy_iron` 为短促锅体共振，表达重砸及破壳；`enemy_ferment` 为错开的低音气泡，表达酸滴与醒面；`enemy_abacus` 为三声木珠敲击，表达粮签和订单结算。声音事件来自实际战斗信号，不触发伤害、不消耗玩法随机。

源程序 `tools/generate_enemy_audio.py` 只使用 Python 标准库，用确定性振荡、包络和固定种子噪声合成，不使用外部采样或音乐。输出 44100 Hz、16 bit、单声道 WAV，峰值 -8 dBFS，淡入淡出，原始参数与生成器保留。四音效沿用项目原创素材授权，无第三方音源许可负担。

通过 `python3 tools/generate_enemy_audio.py` 生成，`--verify` 逐样本重生成并核对 WAV 格式、SHA-256、时长、峰值与非静音。Godot 导入后验证声音入口、暂停不响、限流和清理；这些自动检查不代替扬声器听感。现有七首 BGM 和 28 音效不重生成。
