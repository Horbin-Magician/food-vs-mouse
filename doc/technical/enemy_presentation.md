# 新鼠群技能表现接入

日期：2026-09-26。状态：实施规格；验证结果另记。依据[鼠群重设计](../design/chapter_enemy_redesign.md)和[F 美术规格](../art/chapter_enemy_redesign.md)。

`EnemySkillFeedback` 负责新增预警、酸液／醒面地面效果、盾条、暴露、订单珠及短促命中效果。它只读取 `CombatController.abilities` 的预警和地面状态，以及单位技能字段；不推进业务计时、不调用伤害、不使用玩法随机源。有效预警直接来自运行列表，不进入有数量上限的装饰效果队列，来源取消立即消失。

主战场继续使用原有布局与 F 图集。中央棋盘右侧空白处显示窄幅首领信息：独立名称、生命、盾、当前技能、订单进度及简短提示；不占棋盘或卡牌，不要求点击。首次新鼠提示沿用底部操作提示，主动放置、锅铲和暂停提示优先。完整外形说明与背景故事在敌人悬停中查看，允许暂停后阅读。

图集仍由 `ArtCatalog` 提供，`rank` 决定显示尺寸、名字和命中区域，不能只判断旧 boss/elite ID。普通四动作和独立技能图集映射按实际资产可用性登记；轨迹、落点和订单珠采用代码绘制，其时机完全来自技能状态。美术动画不修改命中判定。

独立技能图按准备／执行／恢复三行、每行六帧读取。`ability_duration` 与 `ability_remaining` 提供当前动作进度；瞬时命中在实际 `skill_used` 之后显示 0.24 秒执行、最多 0.41 秒恢复。受击与死亡优先显示基础对应动作，但不遮掉地面预警。铆壳、铆钳及铁釜的破壳状态分别选择无壳资源；无壳重击也必须使用同状态的技能图，不能出招时恢复完整外壳。铆壳六段提示按剩余护甲次数逐段熄灭。

事件在触发时记录 `CombatController.abilities.clock`。这是每个战斗子步推进、清场归零的游戏时钟，既适用于 `RunController.advance`，也适用于验收画廊直接调用 `combat.step`。表现刷新读取当前时钟与事件时刻之差，不把整帧 delta 追加给本帧末才出现的效果；暂停时无战斗推进，帧号也不变。表现层的 `advance(delta)` 保留调用接口，但技能与装饰年龄以此战斗时钟为准。

持续的 action（冲刺、醒面覆层）优先按 `ability_duration/ability_remaining` 映射执行行；不再先播一段瞬时命中的六帧，再回到持续进度开头。瞬时命中在同一子步进入 normal/recovery 时，才使用 0.24 秒执行覆盖；死亡仍立即取消技能帧选择。相同战斗对象清场导致时钟回退时，旧装饰同时清理。

输入不变：所有特效与首领信息不拦鼠标。暂停冻结计时与装饰，关间按全局关号清理，重开解绑旧信号。验收覆盖两尺寸下七路、边界裁切、并发预警、死亡取消、暂停与 2×，以及悬停真实属性和新／旧首领兼容。

2026-09-26，macOS、Godot `4.6.3.stable.official.7d41c59c4`，获准的本机环境执行以下隔离 QA 专项并通过：

```sh
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --script tests/test_enemy_presentation.gd -- --qa-test
```

真实夹钳蓄力剩余 0.5 秒时，模拟 2×、0.25 秒一帧，命中在末子步发生；刷新后效果年龄接近 0，保留第一执行帧。真实溜勺冲刺与白酵覆层跨过 0.24 秒时帧号不回退，随后按各自时长前进；暂停保持帧号。这些夹具同时使用 `run.advance` 与 `combat.step`，未手工补写局内 elapsed。既有重砸先执行后恢复、被动接盾、死亡、绑定和清理断言也通过。本节不代替原生窗口的视觉验收。
