# 关前三级难度

状态：已实现，自动与窗口交互验证通过，整局平衡待试玩（2026-09-26）。适用内容齐备／使用体验／平衡迭代，基线见 [TODO](../TODO.md)。

每关小铺提供简单、普通、困难三个互斥选项，购物完成时按当前选择开战。新局默认简单；下一关沿用上关选择但可修改；继续游戏恢复已保存选择。战斗、暂停和结算阶段不可修改。重复选择无副作用；非法 ID 拒绝。保存失败回退选择并显示错误。

| 稳定 ID | 显示名称 | 敌人生命倍率 | 敌人伤害倍率 |
|---|---|---:|---:|
| easy | 简单 | 1.00 | 1.00 |
| normal | 普通 | 1.25 | 1.25 |
| hard | 困难 | 1.50 | 1.50 |

简单完全沿用当前配置（含组合鼠潮）。倍率在原关卡倍率之后相乘，适用于普通鼠、精英、首领和召唤物；首领仍不受关卡成长倍率影响，但受难度倍率影响。保留浮点数值。只改生命和攻击伤害，数量、出怪节奏、路线随机、移速、护甲、技能、漏怪扣粮、价格、热量、美食和恢复不变；通关货币收益按下述规则缩放。三档使用同一玩法与随机消耗；倍率是初始调参，真人整局平衡待验证。

DifficultyDef 自定义 Resource 保存 ID、名称、生命、伤害和收益三个正有限倍率，Catalog 固定按简单到困难加载并校验。RunState.difficulty 保存当前关选择；RunController.select_difficulty 校验阶段并持久化；CombatController 生成运行实体时读取倍率，不修改共享资源。UI 在选项上直接显示倍率与选中状态，战斗关卡栏显示名称。

v2 准备快照新增 difficulty；缺字段的 v1/v2 旧档默认为 easy，未知 ID／非字符串拒绝恢复，不升级存档版本。切换不消耗金币或随机数、不刷新商店、不治疗单位。重开回到 easy。

验收：三档八关全敌人数值、简单与原公式一致、召唤物、资源不变、同种子生成表一致；准备切换／重复／非法／战斗拒绝；跨关沿用、新局重置、保存失败回退、往返恢复与旧档兼容；窗口选项、开战与两种尺寸布局。结果见 [专项验证](../testing/difficulty.md)。

## 难度收益（2026-09-26）

按用户要求，简单／普通／困难的通关金币与灵感分别乘以 1／1.25／1.50。第 1～7 关金币先合计基础奖励与符合条件的少漏怪额外奖励，再乘系数并四舍五入；第 8 关仍只发灵感。灵感每关独立乘系数并四舍五入，0.5 向上取整。初始金币、热量生产／恢复、价格和击杀统计不变，开发模式仍不发灵感。

DifficultyDef.reward_multiplier 保存收益系数。通关时按本关难度计算金币，并将实际灵感金额写入 RunState.inspiration_earned（关号字符串→整数）。SaveService 按原有已领奖关数流水仅发未领关；战报使用相同金额记录，不按最终难度重算。保存失败后改难度、重试、失败／放弃及重复结算均不能改变已通关金额或重复领奖。

v1/v2 旧快照缺少 inspiration_earned 时视为空字典；未记录的历史通过关按原基础金额展示，不追补倍率差额。新增记录仅允许已通过的 1～8 关及非负整数金额；恢复时复制字典，未知／非法字段拒绝。验收覆盖三档、额外奖励与无额外奖励、取整、混合难度、读档、写失败重试、最后一关、重复领奖及战报一致。
