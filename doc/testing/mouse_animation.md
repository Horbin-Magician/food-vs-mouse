# 鼠群逐帧验收

状态：专项已通过；2026-09-13 工作区。设计依据 [单位动画](../art/animation.md#鼠群逐帧动画2026-09-13)。环境 macOS、Apple M4、Godot 4.6.3、Compatibility、1280×720。

## 资产与处理

八种鼠群各 6×4 格（移动、攻击、受伤、死亡），共 192 帧。内置 imagegen 基于本项目原创角色生成，提示词与来源见 [生成记录](../art/generation_prompts.md)。首次生成和一次去背景尝试未获得真实透明，初次视觉验收不通过；用户随后明确授权本地脚本处理。

已用 `tools/clean_mouse_frames.py` 去掉棋盘背景、恢复跨格脚部/尾巴/道具，统一缩放、基线并重新排帧。当前 `assets/art/mouse_frames/` 为最终 RGBA；原 RGB 位于 `assets/art/source/mouse_frames/`，有 `.gdignore` 排除导入/导出。离线依赖版本、许可与复现命令见设计文档，无新增游戏运行依赖。正式战场已删除草稿回退，直接使用动画帧。

## 原生窗口操作

使用 Godot 编辑器打开并运行两份验收场景，通过原生窗口输入操作：

- 图集预览：Space 暂停、右箭头逐帧，确认所有动作从 1/6 到 3/6；2 键显示 2×，暂停时帧不变，恢复后继续播放。拖动窗口放大后全图完整。
- 实际战场：鼠标点击暂停后，尸体、敌人姿态、热量和波次保持不变；放大窗口后确认脚底与阴影位置正常；点击 2×、继续后热量、鼠群位置与动作继续推进，尸体到期消失。测试结束已关闭本次运行窗口。

## 边界

死亡仅保留表现快照，立即退出伤害/目标列表，不重复击杀结算；漏怪不播放死亡。阶段切换清除残影，最后一鼠不会为了播放死亡而延迟结算。受伤可打断攻击画面，但不改变业务攻击周期；攻击画面从真实出手事件后开始，无额外预判蓄力。
