# 全局 UI 视觉与交互规范

状态：已实现；自动回归、实际渲染与窗口鼠标检查见 [UI 验证](../testing/ui.md)。适用：首版「使用体验」里程碑，2026-09-13 全界面优化。玩法与几何沿用 [TODO](../TODO.md) 和 [棋盘布局](perspective.md)。

## 视觉体系

采用现代深夜食堂风格：墨绿背景、奶油白正文、薄荷绿主操作、暖金资源、珊瑚红危险提示。弱化木纹、瓷砖和重复描边，让原创角色与棋盘成为视觉中心。8/12/16/24 像素间距、10–16 像素圆角，统一按钮、悬停、选中、禁用、键盘焦点和提示气泡。中文沿用系统字体回退，无新增外部资源、字体、插件或依赖。

顶部保留资源、最多八卡及锅铲；第二行区分主流程、暂停速度和管理操作。卡牌将图像、名称、星级、费用和冷却分层，不在卡片边缘叠写文字。选中使用边框及底色，冷却使用数值与进度，不能仅依赖颜色。准备阶段卡片标记「开战后放置」，费用不足或暂停明确显示原因。

棋盘保持 (352,180) 至 (910,614) 的 7×9 正方形网格。左侧利用棋盘旁空白展示品牌、阶段、目标及当前操作说明；底部左侧保持留空。右侧面板避开棋盘与入口：小铺商品直接展示价格、拥有/升星进度及用途，食谱直接展示效果，战报展示结果与统计。面板可收起，战斗默认隐藏；收起按钮保留可发现性。底部右侧继续显示真实生成进度，不把满条当成胜利。

## 状态与边界

- UI 只读取状态、请求业务接口。购买、维修、暂停、放置与阶段限制沿用业务校验；禁用操作附说明，不改变费用和规则。
- 顶部提示保留错误、存档结果、悬停详情和可跳过的三步引导；详细单位说明同时放入卡牌悬停。
- 铲除与重开使用统一风格的确认弹窗，明确结果、确认与取消。弹窗打开时棋盘不接收操作。
- 选择、调位、锅铲互斥，右键/Esc 取消。准备、战斗、暂停、选谱、胜败均展示明确的阶段与下一步。重开清除残留选择。
- 逻辑分辨率 1280×720，按现有 canvas_items 等比缩放，不引入移动端适配。八卡、长中文效果、售罄、满星、金币不足、食谱为空与十二食谱清单均应保持边界内可用。
