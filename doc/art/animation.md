## F 小笼包逐帧接口（2026-09-25）

- 优先级：死亡＞受击＞放置＞调位＞攻击＞待机。帧内已绘变形，不再叠加整图呼吸／挤压；放置纵向位移、调位弧线和地面影子继续使用既有坐标逻辑，防止画面与格子错位。
- CombatController 新增 `food_hurt(unit)`（非致死扣血后）、`food_fallen(unit)`（致死移除前）两个同步信号。现有 `unit_died(food_id)` 与结算顺序不变；UnitAnimator 仅为 bun 订阅表现，死亡复制显示快照后业务立即移除。尸体没有血条、不能被攻击、不占格、不保存；重复扣血已移除单位不重复生成快照。
- `food_corpses` 与鼠群残影分开维护，0.72 秒到期，阶段切换／读档／重开清空。游戏 delta 为零时帧与残影时间冻结，倍速随实际游戏 delta。其他美食不新增受击／死亡帧。

## 既有程序动作（小笼包以以上逐帧接口为准）

- 其余七种美食待机轻微呼吸，各 ID 有独立幅度与节奏，实例相位错开，不消耗玩法随机数。
- 成功放置美食／生成老鼠播放 0.38 秒落地回弹；失败操作无动画。恢复存档不重播放置。
- 六种攻击美食在实际出手时后坐或前冲；布丁产热时弹跳，吐司受击时防御挤压，不凭空增加攻击。鼠群攻击采用下文动作帧。
- 老鼠仅在未被阻挡时走路，步幅按实际移动距离推进，所以减速、鼓舞和狂暴会影响步频。阻挡后切回待机／攻击。
- 准备调位与交换立即提交逻辑位置，双方在 0.32 秒内沿弧线移到目标；连续调位从当前显示位置接续，同格操作无动画。美食战斗时不自行行走。
- 美食优先级：调位／放置叠加出手，出手覆盖待机姿态，受击闪白独立叠加。影子留在地面，血条随显示脚点移动，鼠标命中仍以目标逻辑格为准。鼠群优先级见下文。
- 表现状态由 UnitAnimator 独立持有。BoardController 发 placed(unit)、moved(unit, from_row, from_col)，CombatController 发 acted(uid)，仅成功业务事件发出。移动通过实际 x 差识别。退出战斗清除动作，移除实体清理缓存，重开／读档更换状态时重建绑定。
- 战斗使用 RunState.elapsed 的实际增量；暂停冻结全部表现。准备使用现实 delta（不受战斗倍速影响），选谱／胜败冻结。时间不写入共享 Resource 或存档。

验收：全部 ID 覆盖、出手同步、交换与连续移动、移除清理、暂停／2×、导入及现有逻辑回归；原生窗口观察待机、放置、攻击、行走与准备调位。不得用自动测试代替视觉检查。

## 鼠群逐帧动画（2026-09-13）

状态：已实现并完成专项验收。192 帧透明图集与状态切换已在正式战场启用，替代鼠群整图摇摆；美食保持现状。

- 八种鼠群各一张透明 6 列×4 行动作图集；每行依次为移动、攻击、受伤、死亡，每动作六帧。固定画布、朝左、脚底基线一致，不逐帧裁成不同大小。
- 移动以实际距离推进六帧循环：前脚触地、承重、交叉抬脚、另一脚触地、承重、交叉；手臂反向摆动、头部小幅起伏。每移动 12 逻辑像素完成一轮，停止后使用攻击末帧的双脚落地姿态。
- 攻击由实际 acted 事件触发，0.48 秒：探头出手、接触、收手复位；受伤 0.30 秒：闭眼缩头、手护身、膝盖弯曲后复位。死亡 0.72 秒：失衡、松手、屈膝、侧倒、落地、停留。不同角色保留背袋、骨头、锅盖、鼓、厨具。
- 优先级死亡＞受伤＞攻击＞移动＞静止；受伤不改变伤害与攻击计时。死亡在业务移除时复制只读显示快照，不再参与目标、阻挡、掉落或通关计数。漏怪不播放死亡；阶段切换、重开清理残影，最后一鼠不延迟通关。
- 暂停冻结帧，倍速随游戏时间，移动减速随实际距离。帧纹理缓存，不在每帧创建纹理。
- 验收：八个 ID 的四动作、图集透明与边界、攻击/受伤/死亡事件、死亡单次结算、暂停/倍速/重开、Godot 导入与回归、原生窗口逐帧检查。资产由内置 imagegen 基于本项目原创鼠群生成，无新增运行依赖；提示词见生成记录。

实际验证与当前阻塞见 [鼠群逐帧验收](../testing/mouse_animation.md)。
