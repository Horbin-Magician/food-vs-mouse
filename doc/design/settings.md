# 设置窗口与战斗快捷操作

状态：已实现；36 项回归、原生输入专项及两种尺寸渲染通过，真实鼠标复验限制见 [专项记录](../testing/settings.md)。适用首版「使用体验」里程碑；沿用 [页面流程](screens.md)、[存档规则](../technical/runtime.md) 与 [音频设置](../art/audio.md)。

## 布局

- 左上热量卡保留火焰与热量数值，下方改为紧凑的「1× 速度／2× 速度」切换按钮；移除原左下暂停、倍速和声音入口。棋盘与美食卡的位置不变。
- 右上角提供带齿轮图标的「设置」按钮，锅铲仍保留独立入口。主菜单、卡册、商店、战斗和战报均可进入设置。
- 设置沿用墨绿、奶油白、薄荷与暖金主题，分为状态提示、三路音量与静音、继续／返回和离开操作。1280×720 与 1600×900 等比缩放下不得裁切或覆盖相邻按钮。复用原创资源，新增手绘齿轮 SVG `assets/ui/settings.svg` 作为项目源资源，无第三方素材或新增依赖。

## 输入与暂停

- Input Map 的 `open_settings` 绑定 Esc；`cancel_selection` 仅绑定右键。Esc 清除选卡、拖动、锅铲和待调位状态后打开设置，包含商店遮罩上方；商店本身仍不可用 Esc 关闭。
- 战斗中打开设置立即暂停模拟及战斗表现，关闭／Esc 返回打开前的暂停状态；「继续游戏」明确恢复战斗。准备、菜单和战报不触发战斗暂停。
- 设置存在时阻断底层购买、放置、拾取、锅铲与倍速操作。右键只取消战场选择，不打开设置。按键长按不得重复开关。
- 关闭设置返回原页面，购物状态与倍速保留。退出场景、胜败切换及重复打开不得恢复旧对局或留下暂停、光标与音频订阅。

## 返回主菜单与退出

- 设置提供返回主菜单（主菜单本页隐藏）与退出游戏。对局内操作先显示确认，取消返回设置并维持暂停；确认后由入口场景执行，窗口只发请求。
- 战斗中说明「继续游戏回到本关开战前，已赚灵感保留」；不保存战斗现场、不结算或删除进行中对局。准备阶段离开先保存，写入失败留在设置并显示错误。
- 战报离开继续使用既有幂等结算与失败重试；卡册返回主菜单保持已保存的卡片资产。新局覆盖确认沿用原流程。
- 音量与静音即时生效、独立自动保存，失败信息可见；试听沿用原服务，倍速不改变音高。
- 确认退出后停止场景操作并防止重复提交，SoundService 停止播放、解绑并等待音频线程释放流资源（最多一秒）后退出进程，避免立即退出与混音线程清理竞争。
