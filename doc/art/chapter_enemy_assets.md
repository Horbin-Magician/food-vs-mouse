## 2. 提示词与来源归档

完整提示词逐文件归档在 [`prompts/chapter_enemies/`](prompts/chapter_enemies/)，文件名与对应源图相同、扩展名 `.txt`。基础提示词统一指定 F 色块、四足、左朝向、24 独立姿势；技能提示词明确三行动作以及不画会与真实技能落点冲突的液滴、轨迹或范围圈。

每个基础角色独立生成；`skewer_marshal` 首次请求网络失败，随后重试成功。风哨基础图因越格用工具作过一次留白修订，精确分格仍需整理。铁釜基础与技能各用一次针对性编辑，将两枚可见铜钉改为三枚清楚的三角铜钉；双勺精英基础与技能各用一次编辑去除生成器多画的第三匙碗，保留两只朝前的匙碗和向后的长柄。上述四张修订均已逐图目视确认，废版原图存于 `source/chapter_enemies/revisions/`，不会参与正式打包。

铆壳鼠、铆钳监工的有壳基础与技能四张源图随后通过内置工具作局部修订，补强铜钉轮廓与刻痕。铆壳基础一次编辑，其余三张各再作一次细槽修订，共七次请求；旧稿与中间稿保留在 `revisions/`。完整提示词分别为 `_rivets_fix.txt`、`_grooves_fix.txt`。交付前只读连通检查发现两张技能的最后修订出现相邻角色粘连，不能作为后续整理输入：铆壳技能最后稿仅 15 个主块、中间稿 16 个；监工技能最后稿仅 17 个。两张最后稿归档为 `_v3_invalid_connected.png`，不参与打包。

最终选择保留两张基础修订，铆壳技能按原字节选回 `rivet_guard_skill_v1.png`（18 个独立主块），监工技能选回 `rivet_foreman_skill_v2.png`（18 个独立主块，三钉轮廓清楚）。四张正式源图每格主块数依次为 24／24／18／18，没有缺格或同格双主体；以 alpha>8、主块至少 1,000 像素、全图连通域中位位置分组，只读取像素，没有分割或写回图片。最终源 SHA-256 已同步来源清单，没有运行离线图像处理。

未使用概念板裁片冒充动作资源。额外形态通过内置工具基于本角色原稿编辑，保留原始基础源图。完整提示词还保留 `_fix.txt`、`_skill_fix.txt` 和风哨 `spacing_revision.txt`，可以区分初稿与修订。

## 3. 透明与图集整理

源 PNG 均有真实透明 alpha，但不能仅凭 RGBA 模式判定合格：已读像素确认背景大部分 alpha 为 0，另有 alpha 1～8 的残留及部分尾巴／道具跨名义分格。工具预览显示的灰红底和红色点边大量来自透明像素的隐藏 RGB，并非正常合成后的外观；仍须检查实际 alpha 合成，不能凭此忽略不透明异常。

例如首版铁釜原稿 `1536×1024` 共 1,572,864 像素，其中 914,071 完全透明，88,227 像素 alpha 为 1～8，左上角为 `(49,39,40,0)`。这一统计只解释源图，不代表边缘验收通过。

离线工具 [`pack_chapter_enemies.py`](../../tools/pack_chapter_enemies.py) 复用现有 F 管线的连通主体提取与预乘 alpha 缩放；不新增画笔、不造帧、不改角色设计。它要求显式 `--authorized-offline-processing`，仅在用户允许离线整理后运行。源图不覆盖，运行图保留 16 px 透明边与 `y=220` 脚点；打包报告记录源／输出 SHA-256、源边界、缩放和逐帧边界。不能用等分硬裁切断越界尾巴。

同角色基础、技能和卸壳使用共同中性首帧参考宽度，再按全组最大姿态统一收小以满足边界；避免每张单独缩放带来体积突变。`--ids` 选择完整角色组，不遗漏其他变体的尺寸约束。开发时环境为 Python 3.12.14、Pillow 12.3.0（HPND）、NumPy 2.3.5（BSD-3-Clause），均来自已配置的工作区运行时，只供离线工具使用；无新增游戏运行依赖。来源分别为 [Pillow](https://python-pillow.github.io/) 与 [NumPy](https://numpy.org/)。

截至本页更新，离线整理尚未执行。主任务已逐项验证来源清单 SHA-256，将全部 37 张最终原稿按原始字节复制到运行目录并完成 Godot 导入，包含铁釜和双勺精英的修订图。这套文件仅供完整接入预览，不能作为最终图集验收通过的证据。离线裁切、统一缩放、透明边整理与排帧仍等待用户明确授权。

## 4. 验收要求与当前边界

[`test_enemy_art.gd`](../../tests/test_enemy_art.gd) 检查：16 个唯一角色、19 基础图与 18 技能图齐全；每帧非空、真实 alpha、256 单元、16 px 隔离、脚点上限；每动作行至少四个不同帧内容；卸壳资源与原形不同，头像和状态 API 映射正确。[`test_art.gd`](../../tests/test_art.gd) 的总数按目录清单计算，扩展为 44 个图标并继续严格检查头像透明边。

目视原稿已确认四足、左向、F 色调、独立主道具与走攻伤倒变化；18 套技能均有独立准备、执行、恢复动作，无壳技能不会画回铁锅或铁甲。铁釜可见三铜钉和双勺多余匙碗已通过工具修订。铆壳基础、监工基础与技能已补强三角铜钉轮廓，铆壳技能保留可独立整理的原版两钉装饰。**壳面刻痕是固定装饰，六次护甲命中由独立六段状态提示逐次熄灭，静态纹样不暗示剩余次数。**

最终选稿仍存在以下可见细节差异（行列从 1 计数）：铆钳监工基础及技能的部分双槽合并为粗斜槽，例如各自第 1 行第 1 格；铆壳技能保留两枚铜钉的旧版外观，例如第 1 行第 1 格，优先保证相邻动作图形不相连。铆壳基础双槽清楚，倒地帧按原姿势保留壳面遮挡。这些差异按制作规范的固定装饰与透视遮挡规则评估，不把源图描述成每帧均有六条可辨细槽。所有选稿仍有真实 alpha=0 背景，低 alpha 边尚需统一整理，不能据此标为透明隔离通过。
