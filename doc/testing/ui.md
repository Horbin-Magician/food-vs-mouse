# 全局 UI 优化验收

状态：已实现，自动回归、真实渲染和窗口鼠标检查通过。范围：2026-09-13 工作区「使用体验」UI 优化，设计依据 [UI 规范](../art/ui.md)。不替代完整八关真人、平衡或发行验收。

## 环境与隔离

macOS、Apple M4、Godot 4.6.3 stable、Compatibility/OpenGL 4.1 Metal；逻辑 1280×720。自动及窗口测试使用 `--qa-test` 隔离存档，未修改玩家存档、数值资源和棋盘坐标。未增加外部资产或运行依赖。

工具默认定位 Godot 编辑器，无法直接选中独立游戏实例。此次将本机同版本 Godot 可执行文件复制到 `/tmp` 的独立 QA 应用标识并做本地临时签名，只为定位测试窗口；随后通过原生 UI 工具操作真实游戏窗口。该临时包装、截图与日志不进入仓库，不作为游戏发行包。

## 实际结果

- Godot 无界面编辑器导入通过，无新增解析或资源引用错误。
- `python3 tools/run_tests.py` 九组回归通过：animation、builds、content、core、edges、progression、projection、save、UI。覆盖原有费用、重复放置、暂停、存档、升星等必验项；玩法与业务模块保持现有规则。
- UI 增补检查通过：阶段对应的主按钮/暂停/维修禁用状态，金币不足购买禁用，准备/暂停/冷却/热量不足/选中状态，冷却条高度，八卡边界，商店及食谱面板边界，长中文说明的子控件边界，弹窗打开时禁止棋盘输入，面板与棋盘不重叠。
- 实际 OpenGL Viewport 图检查：八卡准备、小铺、三选一、暂停、确认弹窗、胜利与失败战报。发现并修正冷却条默认最小高度溢出、按钮与提示行间距不足、窗口标题背景缺失，以及长中文说明在启用自动换行前被最小宽度撑大的问题。最后一轮 UI 回归及渲染检查通过。
- 真实窗口鼠标（工具驱动）：将第一行第一格小笼包移到第七行第九格，悬停显示生命 180/180；点击开始，选择布丁并在第三行第二格放置成功；暂停后点击空格没有新增单位、热量保持 107，并出现禁止放置说明；Esc 清除选中。恢复后选锅铲、点击布丁弹出确认及暗色遮罩；取消后布丁保留；再次暂停并清除选择通过。
- 使用系统窗口缩放检查默认小窗口与放大窗口：棋盘仍为等大正方形，顶部八卡、控制栏、左侧说明与右下角状态均完整可见，保持比例并出现必要黑边。实际窗口截图约为 640×392 与 1224×768（含标题栏与系统捕获缩放），不是跨设备 DPI 保证。
- `git diff --check` 通过。新增主题脚本及 UID 为源文件；临时应用、日志、渲染图未纳入仓库。
