# 0.1.0 桌面试玩版

状态：首版代码和 macOS 导出已实现，本机启动通过；完整真人试玩与跨机器分发验收待完成。

## 环境与构建

Godot 4.6.3 stable 官方标准版、GDScript、Compatibility；macOS universal（arm64 + x86_64）。本机 Apple M4；Windows/Linux 尚无导出验收。本次根据可用设备先提供 macOS 包，未修改桌面平台基线。

使用 [Godot 官方 4.6.3 模板](https://godotengine.org/download/archive/4.6.3-stable/) 中的 `templates/macos.zip`。模板 MIT 许可，具体来源见 [资产说明](../art/presentation.md)。Python 3 仅用于开发工具，无运行时 Python 依赖。

```sh
python3 tools/run_tests.py
python3 tools/export_macos.py --template /path/to/macos.zip --output /path/outside/repository/MidnightKitchen.zip
```

可用 `GODOT_BIN` 指定同版本引擎路径。导出工具复制必要源资源到临时目录再构建，不污染仓库导出配置；不包含 tests、tools、doc 和开发场景。universal 导出要求的 ETC2/ASTC 和 S3TC/BPTC 导入开关已开启，渲染器仍为 Compatibility。

## 启动与操作

解压后启动 `food-vs-mouse.app`。开局在小铺购买卡，点击开始鼠潮；选卡再左键点格子放置，右键或 Esc 取消。准备阶段先点原单位再点目标移动或交换。维修每阶段一次，战斗铲除须确认。右侧选谱和商店按阶段显示；暂停不允许放置。

此包使用本地 ad-hoc 签名，未做 Apple 公证；已通过本机启动，尚未验证新机器的下载／系统放行流程。该状态不能等同于正式签名发行。

## 存档与遥测

格式版本 1，位于 Godot `user://`，局外 `meta.json` 与局内 `run.json` 独立。战斗退出恢复本关准备快照；关间购买、选谱、调整和维修自动保存。损坏或未知版本提示重新开局，独立有效的局外进度保留。

每局结束在 `user://runs/` 写一份 JSON（运行 ID 哈希命名），包含种子、关卡、战斗时长、伤害、阵亡、粮损、溢出及食谱。数据只写本机，不联网。重开会结束当前局并结算已达成的解锁。

开发源工程用 `-- --dev --qa` 启用 F3 和隔离 QA 存档；发行构建忽略 `--dev`，无作弊面板。QA 目录与正常玩家目录分离。

## 验证与限制

见 [实际测试](../testing/implementation.md) 和 [平衡记录](../testing/balance.md)。两种自动策略已用正常规则通关，不算真人局。当前为原创占位画面和基础合成音效；无最终美术或音乐。至少 5 人 15 局、20–25 分钟常规体验、资源经济与单一最优解仍待真人验收。没有据两局自动策略静默修改设计基线的初始数值。
