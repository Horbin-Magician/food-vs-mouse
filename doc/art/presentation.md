# 首版表现与来源

状态：基础表现已实现，视觉可读性待新玩家验收。范围：首版画面与音效，当前角色权威规格见 [F 全角色规范](f_restyle.md)，环境与食谱规格见 [美术资源包](asset_pack.md)。

- 墨绿食堂背景、奶油/鼠尾草等大矩形格子、暖色美食、灰色鼠群；全局 UI 样式依据 [UI 规范](ui.md)，坐标与深度规则见 [棋盘布局](perspective.md)。美食以颜色、轮廓和中文名共同识别；鼠群添加锅盖、鼓、面粉袋、厨师帽等轮廓。首领／精英体型增大。
- 角色与环境已采用本项目主题生成美术（见资源包来源记录），格子、UI、血条与状态由程序绘制；项目图标采用原创小笼包与灰鼠对峙图，来源、配置及验收见 [项目图标](project_icon.md)。旧 `icon.svg` 蒸汽碗标志保留为历史资产。中文文字使用 Godot 系统字体回退，不随包分发外部字体。
- 白色受击闪烁、血条、低生命红色提示；减速雪花与灼烧热气图标；射程悬停叠层。音频由 `SoundService` 统一播放离线原创资产，覆盖菜单、卡册、小铺、战斗和战报；混音及事件依据 [全游戏音频](audio.md)，来源与生成方式见 [音频资产](audio_assets.md)，未引入第三方曲目或运行插件。
- Godot 引擎与官方导出模板 4.6.3 stable 为 MIT 许可：[官方许可](https://godotengine.org/license/)、[官方版本来源](https://godotengine.org/download/archive/4.6.3-stable/)。模板只用于构建，不提交仓库。
- 角色图集、厨房背景与食谱图标已接入；小笼包与鼠群使用逐帧动画，其他美食采用脚底锚定的呼吸、入场回弹、出手与调位，详见 [单位动画](animation.md)。不同鼠群辨识、音量舒适度仍需真人反馈；音频实际验证单列记录。

验收：真实窗口检查中文、格子边界、顶部卡牌和可收起浮层；操作反馈与暂停一致；发行包中文显示和素材引用可用。具体结果见 [验证记录](../testing/implementation.md)。
