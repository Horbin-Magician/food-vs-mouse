# 整局三级难度

状态：整局选择已实现，自动与原生渲染验证通过；鼠标复验受工具限制，整局平衡待试玩（2026-09-26）。适用内容齐备／使用体验／平衡迭代，基线见 [TODO](../TODO.md)。

新局在局外「出战阵容」页统一选择简单、普通、困难，默认简单。点击出发创建对局时锁定，整局八关共用；首关和后续小铺仅显示难度，战斗、暂停、结算和继续游戏均不能修改。返回菜单后新开一局／再守一夜重新选择，默认简单；局外切换页签和选卡不清除待选难度。有进行中对局时卡册只读，显示存档中的难度且选项不可操作。非法 ID 在创建对局前拒绝，不结算或覆盖原局。创建快照写失败不进入对战，保留出战页选择以便重试。

| 稳定 ID | 显示名称 | 敌人生命倍率 | 敌人伤害倍率 |
|---|---|---:|---:|
| easy | 简单 | 1.00 | 1.00 |
| normal | 普通 | 1.25 | 1.25 |
| hard | 困难 | 1.50 | 1.50 |

简单完全沿用当前配置（含组合鼠潮）。倍率在原关卡倍率之后相乘，适用于普通鼠、精英、首领和召唤物；首领仍不受关卡成长倍率影响，但受难度倍率影响。保留浮点数值。只改生命和攻击伤害，数量、出怪节奏、路线随机、移速、护甲、技能、漏怪扣粮、价格、热量、美食和恢复不变；通关灵感按下述倍率缩放，击杀灵感掉落概率按各难度独立配置。三档使用同一玩法与随机消耗；倍率是初始调参，真人整局平衡待验证。

DifficultyDef 自定义 Resource 保存 ID、名称、生命、伤害和收益三个正有限倍率及独立灵感掉落概率（0～1），Catalog 固定按简单到困难加载并校验。RunState.difficulty 保存整局选择；RunController.new_run 在创建状态前校验难度 ID，并将其写入首个准备快照；移除局内 select_difficulty 接口；CombatController 生成运行实体时读取倍率，不修改共享资源。UI 在选项上直接显示倍率与选中状态，战斗关卡栏显示名称。

v2 准备快照新增 difficulty；缺字段的 v1/v2 旧档默认为 easy，未知 ID／非字符串拒绝恢复，不升级存档版本。旧档已保存的难度成为余下整局固定难度（包括首关准备快照），历史收益不重算。局外切换不消耗资源或随机数、不刷新商店、不治疗单位。重开回到 easy。

验收：三档八关全敌人数值、召唤物、共享资源不变、同种子生成表一致；局外选择／重复选择／页签保留、非法 ID 不覆盖原局；首关及关间无切换入口、八关沿用、继续恢复、新局重置、写失败留在出战页；旧档默认及旧收益兼容；两尺寸布局与真实鼠标出发。结果见 [专项验证](../testing/difficulty.md)。

## 难度收益（2026-09-26）

简单／普通／困难的通关灵感乘以 1／1.25／1.50，每关独立四舍五入，0.5 向上取整。2026-09-26 取消金币；灵感掉落概率按难度独立配置，不再乘该收益系数，完整规则见 [经济设计](economy.md)。热量价格、生产／恢复不受难度影响，开发模式仍不发灵感。

DifficultyDef.reward_multiplier 保存收益系数。通关时按本局难度将实际通关灵感金额写入 RunState.inspiration_earned（关号字符串→整数）。SaveService 按原有已领奖关数流水仅发未领关；战报使用相同金额记录，不按最终难度重算。保存失败后重试、失败／放弃及重复结算均不能改变已通关金额或重复领奖。

v1/v2 旧快照缺少 inspiration_earned 时视为空字典；未记录的历史通过关按原基础金额展示，不追补倍率差额。新增记录仅允许已通过的 1～8 关及非负整数金额；恢复时复制字典，未知／非法字段拒绝。验收覆盖三档、不同漏怪数量不产生热量奖励、取整、旧版混合难度记录、读档、写失败重试、最后一关、重复领奖及战报一致。
