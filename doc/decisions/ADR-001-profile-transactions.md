# ADR-001：卡片体系使用单文件事务存档

状态：已采用，2026-09-25。范围：新卡片资产、强化、灵感奖励、商店与进行中对局。

旧版分别写 meta.json 和 run.json；卡片体系要求强化耗材与结果同步，以及每关灵感与下一关快照同步。继续跨两个文件分别替换，需要额外提交日志和恢复状态机；任一文件写失败可能造成复制材料或重复奖励。

选择 player.json v2 的 meta／run 两个独立校验区，采用单次临时文件原子替换，以 revision 拒绝重复旧请求。可解析文件内的 run 字段损坏不清空合法 meta；整个文件不可解析或 meta 损坏时阻止写入，显示错误。代价是物理文件损坏会同时阻止两部分读取，目前无自动备份恢复，不宣称具备磁盘灾难恢复或多进程写锁。

旧文件只读导入并保留；v2 成为权威后不再回退旧文件，以免复制已消耗卡片。原旧档 last_run 导入已结算流水，避免旧版结算完成但尚未清掉 run.json 的中断场景重复领奖。

模块、数据、规则和迁移见 [实施规格](../technical/card_progression.md)，验证见 [验收记录](../testing/meta_progression.md)。此决策替代工程规范中“物理分文件”的隐含约定，仍保留逻辑隔离、独立校验和禁止损坏覆盖的要求。
