# 深夜食堂卡册与备战界面

状态：2026-09-26 已实现，自动、原生画面与关键鼠标验证通过，范围见 [全界面验收](../testing/ui_refresh.md)。范围为局外灵感卡店、收藏、卡片强化与出战阵容；归属首版使用体验迭代。沿用 [全局 UI](ui.md)、[本轮全界面设计](ui_refresh.md)、[局外成长](../design/meta_progression.md)、[难度](../design/difficulty.md) 与 [经济](../design/economy.md) 的规则，不调整费用、概率、存档或关卡。

## 视觉与层级

界面以墨绿柜台、奶油文字、黄铜暖金强调选中与资源，沿用 GameTheme 和现有原创角色肖像，不新增依赖或外部素材。1280×720 等比布局中，顶部放卡册标题、三个页签和灵感余额；左侧呈现卡片，右侧只呈现当前页的决策与主要操作；底部保留交易和只读反馈。

- 卡店：商品卡依次呈现用途、肖像、名称、放置热量、已拥有张数和购买按钮。放置热量明确标注，避免与购卡灵感混淆。已售罄、余额不足及只读不能只靠颜色表达。换货区直接显示本次及刷新后的下一次费用、已刷新次数、结算免费换货规则；右下「去配阵出战」直接进入阵容页。
- 收藏：每卡显式显示用途、等级和放置热量；携带、主卡、材料分别以文字及边框表达。基础卡保护、用户锁定和可消耗状态可见。不能当材料的原因可从卡面读取。
- 出战：固定五个肖像槽位表达已选阵容与空位，显示攻击／阻挡／生产组成。选相同类型的另一个实例会替换原实例，仍沿用业务规则。难度直接显示敌人生命／伤害倍率、通关灵感倍率与掉落概率，说明八关固定；不能出发时，原因直接显示在出发按钮上方。
- 强化：以「1 主卡 → 2 材料 → 3 结果」顺序组织。主卡显示当前永久增益；材料以小肖像和等级展示 1～3 个槽位；结果区同时呈现成功率、失败主卡等级和全部材料会消耗的说明。成功率达到 100% 且预览无错误时，结果标为薄荷色「本次必定成功」，不再显示不可能发生的降级提示，材料消耗警示仍保留。空主卡、空材料与满级各有具体提示。基础卡只显示「不可作材料」，锁定也仅防止作为材料消耗，不表达防降级保护。失败结果以业务预览为准。

## 边界与验收

有进行中对局时保持只读，说明返回主菜单继续或开始新局的路径。购买、刷新、锁定、强化仍由 MetaProgression 执行和校验；UI 不重复计算概率或写入资产。成功后保留即时存档反馈，失败不伪装成功，不增加确认弹窗。

验收包括 Godot 4.6 解析／导入、现有成长与难度专项，检查原测试节点名和信号兼容；统一原生验收检查卡店买不起／售罄、强化零至三材料／高等级失败、备战空阵容／无攻击／满五种、只读和库存滚动，以及 1280×720 与等比放大布局。自动测试不替代真实画面和鼠标验收，实际结果完成后追加。
