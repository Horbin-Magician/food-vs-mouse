# 操作界面整合：深夜食堂菜单与备餐台

状态：2026-09-26 已实现；属于 [首版使用体验](../TODO.md)，不改变玩法、费用、难度、强化概率或存档规则。实际验收见 [专项记录](../testing/ui_refresh.md)，区分自动验证、原生渲染与鼠标操作。

## 目标与视觉

统一为深墨绿食堂、奶油文字、黄铜分隔与暖金主按钮。暖金表示当前最重要的下一步，薄荷表示已选与正常状态，珊瑚色配文字表示风险。保留原创厨房和 F 风格角色；以清楚的标题、留白、少量分隔线和数据块代替重复的大边框。1280×720 逻辑画布及等比缩放不变，无外部依赖或新增第三方素材。

所有按钮共享悬停、按下、禁用和焦点样式；滚动条、提示、确认框及设置沿用同一主题。费用、用途、选择结果和阻断原因应在做决定的位置可见；长参数留在悬停。主操作不能仅靠颜色区分，使用明确动词。

## 主菜单与战报

- 主菜单根据是否存在有效快照，将「继续游戏」或「新的一局」置于首个主操作位置；不存在快照仍保留禁用继续入口和原因，读取失败显示真实错误。
- 保留游戏标题与角色，用「选好美食 → 布阵守夜 → 食谱构筑」简短呈现循环；不是步骤式教学，也不创建战斗提示栏。
- 新局、继续和卡册使用简洁按钮及就近解释；卡册明确用于灵感购卡与永久强化；新局覆盖确认、结算规则沿用 [页面设计](../design/screens.md)。
- 战报以通过关卡、击退鼠群、守卫时间、获得灵感为主要统计，损失与食谱为辅助数据。所有值来自现有 RunState，不新增评分或奖励。
- 战报提供「再守一夜」「美食卡册」「返回主菜单」。卡册入口先调用既有幂等结算，成功后释放战斗进入卡册；失败停留战报并显示错误。退出仍可通过统一设置进入。明确已赚灵感保留，帮助玩家理解下一局准备。

## 设置

保留现有暂停所有权、三路音量、静音及离开确认。新增静态操作速记（左键选择/拖放、右键取消、点击资源收取、Esc 设置），缩短重复说明；它不触发教学、不接收战场操作。窗口加高以容纳内容，1280×720 内留出完整标题、按钮和外侧空间。静音时提示当前静音状态，试听按钮禁用并解释原因。
