# 深夜厨房：场景内五大关连续战役

状态：2026-09-26 已实现；验证结果见[连续战役验收](../testing/continuous_campaign.md)。本文取代[五个独立大关历史方案](campaign_independent_history.md)，是场景、大关、小关、进度及迁移的唯一权威说明。

## 层级与完整一局

- 场景是局外可选择的内容单位。本版只提供「深夜厨房」（稳定 ID `kitchen`），不展示无法进入的其他场景。
- 厨房内五大关是同一层级的五个主题篇章，依次推进；不是五个场景，也不是需要局外逐个解锁的独立对局。每大关八小关，第 4 小关精英、第 8 小关首领。
- 出战页选择场景、1～5 种美食和难度。从 1-1 开始，顺序为 1-8 → 2-1 → … → 5-8；前四个首领清场后直接打开下一大关首关小铺。只有 5-8 所有敌人（含召唤物）清空才整局胜利，粮仓归零优先失败。
- 出战页五大关仅作等层级的路线说明，不提供点击跳关、前置锁、独立再战按钮。继续游戏可恢复已到达的任意大关关前快照。
- 新局只在进入场景时重置为 150 热量、10 粮仓、空阵地、无食谱及新的 `run_id`；阵容、永久强化快照和难度四十关锁定。失败或主动结束后才能在局外购卡强化、重选阵容。
- 每个小关及大关之间都保留热量、粮仓、存活美食的位置和剩余生命、食谱。每次过关只按既有 15%／回炉 30% 恢复一次，不复活、不额外补满粮仓、不另发开局热量。清除弹体、临时状态、拾取物与攻击计时，放置冷却在下关开始清空。
- 小铺只在前四大关通关后出现；新局与普通小关直接开战，第五大关后进入胜利战报。出现时机、旧购物快照兼容与失败重试统一见 [商店设计](shop.md#大关通关后开店2026-09-26)。
- 一局现在是 40 小关；旧 20～25 分钟目标仅适用于历史八关对局，不能继续当作完整一局目标。新版总时长待正常战斗采样与真人体验确认；允许关前存档分次完成。

## 灵感与首通

- 各小关沿用原八项基础灵感表，按大关内小关序号循环，并应用整局难度系数；每次通关记录实际金额。
- 收集、通关奖励及已领奖游标使用整个场景的 1～40 全局小关号，禁止大关切换时把第 9 关再次记为第 1 关。同一场景全程同一 `run_id`。
- 保留每大关首次完成 +12 灵感，首次完成该大关第 8 小关时在下一关快照（最终大关在整局结算）中原子记账。中途失败仍保留已经获得的大关奖励。重复通关不再给首次奖励，重复读档／保存／结算不重复增加通关次数。
- 大关完成记录仅是成就和奖励记录，不再用于解锁或进入校验。前四个首领后不刷新局外卡店，不允许中途更换携卡或强化，不结算整局。
- 失败、主动结束、整局胜利仍使用已有原子结算；写入失败可重试，不能用新局覆盖未完成的奖励事务。

## 数据、接口与 v4 兼容

`ScenarioDef` Resource 定义场景稳定 ID、名称及有序 `chapter_ids`；`ChapterDef` 保持主题和八个 `WaveDef`，移除前置解锁字段。`Catalog.scenes`、`scene_chapters(id)`、`scene_wave_count(id)`、`scene_error(id)` 提供内容查询与合法性检查。`RunController.new_run` 第四参数为场景 ID，业务层拒绝传入 `kitchen_2` 等大关 ID 绕过起点。

`RunState` 保存 `scene_id`、`chapter_id` 和大关内 `wave`，`global_wave()` 为 1～40；累计 `metrics.passed`、奖励字典与流水均使用全局进度。`start_wave` 标识本次实际起始的小关（新局为 1，旧独立大关迁移例外）。运行状态独立于共享定义资源。

player.json 升为 v4，读取原 v1／v2／v3 并在成功写入时迁移：

- v1／v2 无大关 ID 默认厨房第一大关；旧 v3 保留已到达的原大关和本关阵地、热量、粮仓、食谱、难度及携卡。继续后完成该大关，再推进其后大关直到 5-8，不强迫从头开始。
- 旧局仍用原 `run_id`，仅未结算旧局及对应流水按 `(大关序号-1)×8` 偏移奖励键和进度，保存 `start_wave`，此前未实际参与的大关不补通关、不发奖、不伪造阵亡或用时。
- 历史已结算流水和 `chapter_clears` 保留，不重新结算、不推断整个场景已通关。已有首通不再发第二次。
- 未知场景／大关、错配层级、损坏字段、越界奖励键或未来版本拒绝恢复或提交，局外有效资产仍可读取；迁移不能把非法旧值整理成合法进度。
- 保存恢复与灵感最高累计防重沿用[经济规则](economy.md)，全局进度唯一键取代旧 1～8 键；历史快照不能覆盖已经进入后续关卡的流水。

## 本轮验收

里程碑：内容齐备与持续阵地流程修正；不是重新发布候选包。最低验证包括：

1. 场外只有场景入口；业务拒绝独立大关开局；从新档一次连续经过四个大关边界，第五首领后胜利。
2. 1-8→2-1 等边界的阵地／生命恢复／热量／粮仓／食谱／难度／阵容／种子连续，临时效果清理；前四次不显示战报，失败优先。
3. 第 8、9、16、17、32、33、40 小关奖励与收集不碰撞；旧档、重复继续／结算、写失败重试、旧已结算流水不重复发奖。
4. 四十关资源、随机时序、七路合法性、精英／首领位置、召唤预警、暂停倍速和死亡取消。
5. 正常规则从 1-1 起的三卡、蒸汽、冰火构筑采样；不得用分别从空阵地开始的五次八关采样替代连续验证。预置五卡仍标为测试夹具，不能冒充新玩家的真实成长。
6. 1280×720、1600×900 原生窗口检查场景页、跨大关小铺、继续和终局战报，补充实际鼠标交互。未执行项目明确列出，不沿用历史截图或历史 RC 包作为新版证据。

用户此前豁免的真人试玩仍记为「用户豁免／未执行」，自动结果不能证明可学性、声音听感或最终平衡。当前用户工作区已有的历史实现、测试证据和发布记录保留；旧记录属于独立大关版本。
