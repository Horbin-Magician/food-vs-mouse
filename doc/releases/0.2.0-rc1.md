# 0.2.0-rc1 · 厨房五夜

状态：候选包已导出，本机原生启动／继续／拖放／暂停／退出通过；完整 release QA 成长通过，性能均值超过 60 FPS，帧时间尖峰如实列为限制。2026-09-26；Godot 4.6.3、Compatibility、Apple M4。

## 本版内容

同一个厨房扩展为五个独立大关、每夜八小关，共 40 关。通关依次解锁，共享局外卡片与强化；新夜重置局内热量、粮仓、阵地与食谱。八美食、八鼠种与十二食谱保持有限范围。五夜分别强调经营、跑腿侧袭、护甲消耗、面粉死亡位置及混合援军；所有首领援军均有入口预警。背景按夜晚推进调整光色，保留原创 F 角色、逐帧动画、7 首音乐和 28 个音效。本版没有新增独立音乐曲目。

新首通每大关额外 12 灵感；重复通关仍获得普通奖励，首通不会重复发放。小铺在消费前显示下关敌情，战报和继续入口显示大关身份。辣椒伤害调整至 48，理由与同种子对比见 [战役设计](../design/campaign.md) 和 [验收记录](../testing/campaign.md)。

## 启动与操作

解压 `food-vs-mouse-0.2.0-rc1.zip`，打开 `food-vs-mouse.app`。无需 Godot 编辑器、Python 或网络。macOS universal 包含 arm64 与 x86_64；仅 Apple M4 实测，Intel、Windows、Linux 未验收。此包为本地 ad-hoc 签名，未经 Apple 公证；新机器下载后的 Gatekeeper 分发流程未验证。

新局在出战阵容页选择卡片、难度和已解锁大关；小铺用热量购买食谱，点击购物完成开战。鼠标点卡再点格子或拖放，右键取消；锅铲点单位直接移除；点火苗／紫色灵感拾取。Esc 打开设置并暂停；顶部速度在 1×／2×间切换。准备阶段不生产热量，不购买食谱也可直接开战。关间自动恢复阵地，残余热量与食谱保留；下一大关重新布阵。

建议初次使用简单难度。正常规则自动采样的纯战斗时间约 12～14 分钟／夜，不含人的思考、购物和暂停；20～25 分钟原体验目标尚无人类时长证据，不承诺此数值。普通难度第五关 +2 三构筑样本通过，困难为可选挑战，不能从单一样本推导普遍可通。

## 最终包与性能

交付 ZIP 约 77 MB（含启动说明及完整第三方通知），SHA-256：`cde0195399b919e91ef33a4ddfb610a2c7f85dbfb7b9d9965197f879734cf6be`。ZIP 成员 CRC 全部通过；解压后 codesign --verify --deep --strict 通过，lipo 确认 arm64/x86_64。源码导入与最终导出无脚本错误。

完整效果的 release QA 在 1280×720 真实时钟测量：40 美食／100 敌人平均 70.03 FPS，P95 27.85ms、P99 30.67ms；49 美食／100 敌人／两路预警平均 67.53 FPS，P95 28.48ms、P99 31.58ms。平均 60 FPS 目标达到；仍存在短时尖峰，未达到每帧锁定 60 FPS，也未作跨机器性能承诺。保留此限制作为后续优化项，不能用引擎平滑 delta 得到的 145 FPS 替代真实指标。

49/100 完整效果独立复测平均 63.99 FPS（P95 28.08ms、P99 30.65ms），原始记录一并保留；不把较高的单次样本当作稳定帧率保证。最终程序正常窗口退出无脚本／资源错误；强制 --quit-after 的音频退出告警见战役记录。
