# 全局 UI 视觉与交互规范

状态：已实现；自动回归、实际渲染与窗口鼠标检查见 [UI 验证](../testing/ui.md)。适用：首版「使用体验」里程碑，2026-09-13 全界面优化。玩法与几何沿用 [TODO](../TODO.md) 和 [棋盘布局](perspective.md)。

## 视觉体系

采用现代深夜食堂风格：墨绿背景、奶油白正文、薄荷绿主操作、暖金资源、珊瑚红危险提示。弱化木纹、瓷砖和重复描边，让原创角色与棋盘成为视觉中心。8/12/16/24 像素间距、10–16 像素圆角，统一按钮、悬停、选中、禁用、键盘焦点和提示气泡。中文沿用系统字体回退，无新增外部资源、字体、插件或依赖。

顶部保留资源、最多八卡、设置及锅铲；倍速位于热量下方，暂停和声音集中到设置窗口，具体交互依据 [设置设计](../design/settings.md)，棋盘与关卡进度位置依据 [棋盘布局](perspective.md)。卡牌使用紧凑图文布局，展示上方图像、下方费用和右上星内等级，名称和持有进度放入悬停；不保留底部状态文字，锅铲仅显示图标。选中使用边框及底色，冷却使用覆盖整卡、从上至下消退的阴影；状态与剩余秒数放入悬停提示，非法操作仍有明确原因。

棋盘使用 [棋盘布局](perspective.md#当前规则) 定义的扩大后 7×9 正方形网格；顶部贴边下延、底部贴边位置也以该文档为准。左侧不保留信息卡片；底部左侧保留食堂标识。小铺采用居中弹窗，具体规则见下节；战斗已购食谱通过底部关卡进度文字悬停查看，不再提供侧栏开关。胜败使用 [独立结束界面](../design/screens.md)。底部右侧继续显示真实生成进度，不把满条当成胜利。

## 状态与边界

- UI 只读取状态、请求业务接口。购买、暂停、放置与阶段限制沿用业务校验；禁用操作附说明，不改变费用和规则。
- 提示与详情遵循下文「提示栏与引导移除」；详细单位说明继续放入卡牌悬停。
- 主菜单覆盖旧局使用确认弹窗，明确结果、确认与取消。弹窗打开时棋盘不接收操作。
- 选择、调位、锅铲互斥，右键取消；Esc 清除选择后打开设置，规则见 [设置设计](../design/settings.md)。准备、战斗、暂停、胜败均展示明确的阶段与下一步。重开清除残留选择。
- 逻辑分辨率 1280×720，按现有 canvas_items 等比缩放，不引入移动端适配。八卡、长中文效果、售罄、满星、热量不足、食谱为空与十二食谱清单均应保持边界内可用。

### macOS 原生光标兼容性（2026-09-25）

状态：已确定，沿用上述游戏内锅铲实现。属于「使用体验」缺陷修复，不改变玩法。

Godot 4.6.3 的 `platform/macos/display_server_macos.mm:3052` 位于 `cursor_set_custom_image()`：创建 `NSBitmapImageRep` 失败后触发 `ERR_FAIL_NULL(imgrep)`。旧锅铲注册箭头／手形自定义图像会进入此路径。后续定位到编辑器嵌入模式接收空光标时生成空尺寸 Image 并缓存、停止游戏后缓存仍保留的问题，见下文；不能据此断定为资源损坏或内存不足。来源：[Godot 4.6.3 源码](https://github.com/godotengine/godot/blob/4.6.3-stable/platform/macos/display_server_macos.mm#L3019-L3052)。

游戏内工具光标继续使用 CanvasLayer + TextureRect，不注册系统自定义图像；系统只负责指针显示／隐藏。验收覆盖反复拿起／放回、右键／Esc、失焦、窗口离开、隐藏及持有锅铲时释放场景，确保恢复系统指针，并在 macOS 原生窗口检查上述错误不再出现。headless 不能验证 AppKit 路径。旧游戏进程需停止后重新运行；若编辑器已经运行过原生自定义光标版本，还须执行「项目 → 重新加载当前项目」或完全退出并重新打开编辑器，清掉编辑器进程中的光标缓存。仅停止游戏或清空输出无效。旧导出包需重新导出才会包含修复。

### 编辑器嵌入运行的空光标缓存（2026-09-25）

状态：引擎源码已定位，本机重载恢复及嵌入启动／退出验证通过。此项补充上次独立窗口验收的遗漏，不代表修改了 Godot 引擎。

Godot 4.6.3 的 macOS 嵌入调试接收端在收到清除自定义光标的空字节数组时，仍实例化 `Image`；`LayerHost::cursor_set_custom_image` 无条件将其写入 `custom_cursors`。鼠标进入区域时重放该缓存，空尺寸 Image 被传给原生位图创建函数；`EmbeddedProcessMacOS::reset` 仅清除系统光标，没有清空 LayerHost 的缓存。因此旧游戏注册／清除过的箭头与手形可能在后续运行中继续报两条错误，即使当前游戏代码已不再注册原生光标。

依据：[嵌入消息接收](https://github.com/godotengine/godot/blob/4.6.3-stable/platform/macos/editor/embedded_game_view_plugin.mm#L56-L71)、[缓存、鼠标进入重放和 reset](https://github.com/godotengine/godot/blob/4.6.3-stable/platform/macos/editor/embedded_process_macos.mm)。处理方式遵循上文：保留游戏内光标，重新加载编辑器项目清空旧缓存，无须升级引擎、删除 `.godot`、修改存档或关闭嵌入功能。验收见 [UI 记录](../testing/ui.md#编辑器旧光标缓存复验2026-09-25)。
