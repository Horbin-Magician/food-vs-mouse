## 真实鼠标与键盘

在 1280×720 独立 QA 窗口经原生鼠标／键盘完成并检查结果：

1. 主菜单「新的一局」进入阵容页；取消所有攻击卡后，显示缺少攻击美食并禁用出发；重新携带后恢复可出发。
2. 切换普通难度，生命、伤害、通关收益和掉落率同步显示；跨页签保留本次选择。
3. 卡店买卡后灵感扣 4、收藏增 1，连续再次点击售罄位置没有重复扣除；刷新扣 2，再从直接入口返回备战。
4. 出发进入小铺，150 热量下显示食谱还差 350 热量且可直接开战；「购物完成」进入战斗。
5. 拖放小笼包、布丁各放置一次，热量扣除和整卡冷却可见；Esc 清除操作并暂停，关闭后继续；2× 状态保持可辨认。
6. 锅铲拿起后底栏显示立即铲除／无返还，点击已放置美食直接移除，右键取消并恢复指针；Esc 再次暂停。
7. 静音后试听禁用并显示静音状态，取消静音恢复；返回菜单先显示「回到本关开战前、已赚灵感保留」，Esc 取消确认仍在设置内并维持暂停。
8. 确认返回菜单后继续入口成为主操作，继续恢复到关前小铺与 150 热量准备快照；准备阶段退出显示保存说明，确认后 QA 进程正常退出。
