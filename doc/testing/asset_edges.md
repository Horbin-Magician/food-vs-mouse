## 离线复现

[clean_art_atlases.py](../../tools/clean_art_atlases.py) 使用已安装的 Pillow 11.3.0，仅用于开发期处理 PNG，不增加 Godot 运行依赖。来源：[Pillow 项目](https://python-pillow.org/)，许可为 MIT-CMU（依据本机包元数据）。

从上述 Git 版本导出 `assets/art/foods.png`、`mice.png`、`recipes.png` 至独立目录，再执行：

```sh
python3 tools/clean_art_atlases.py --source /path/to/original --output /path/to/clean
```

脚本拒绝同目录输入输出，执行后逐图验证留白并打印缩放和区域统计。不可把当前已修整 PNG 当作原始输入重复处理，否则会再次缩小；接入前必须复核透明与逐格对照。文件源于本项目原有图像，不增加第三方美术。

此前三次内置 image_gen 修图输出为 RGB，未纳入交付；最终交付采用用户续办后授权的程序处理。
