# 美食弹体

日期：2026-09-25。状态：已实现；导入、相关回归和原生渲染通过，真人试玩未执行。属于首版「使用体验」表现补全；玩法依据 [TODO](../TODO.md)，造型遵循 [F 风格](f_restyle.md)。

## 视觉与接入

弹体使用本项目原创 SVG：深蓝轮廓、块面阴影和奶油高光，透明背景，朝右飞行。以形状和颜色同时区别，在默认窗口约 32～46 像素宽，保留透明留白，不遮住相邻行。

| 来源 ID | 弹体 | 识别与尺寸（投影缩放前） |
|---|---|---|
| bun | 奶白螺旋蒸汽团、青灰尾气 | 38×28 |
| bun 且 radius > 0 | 双卷高压蒸汽、金色压力环 | 46×34 |
| tea | 菱形冰块包裹柠檬片，冰蓝碎晶尾迹 | 36×28 |
| pepper | 弯曲红辣椒、绿蒂、橙色火焰 | 42×28 |
| popcorn | 三瓣奶油爆米花、焦糖核心与碎屑 | 34×30 |
| noodles | 三条金黄面条、青绿葱花，细长穿透轮廓 | 46×24 |

吐司不攻击；布丁生产火苗沿用热量系统；蒜香面包仍为即时近战，不新增弹体。未知来源保留原黄点回退。

表现层通过现有弹体 `source` 和 `radius` 选图，不增加存档字段。弹体仍使用原有行、位置、速度、命中、范围和穿透逻辑；图片居中沿既有高度绘制。尾迹属于静态矢量轮廓，随弹体统一移动，暂停和倍速直接遵循现有游戏时间，不读取现实时间或消耗随机数。关间随弹体数组清理，无独立残留节点。

## 来源及验收

`assets/art/projectiles/*.svg` 为本次用路径绘制的原创源资产，无第三方素材、插件或运行依赖；Godot 原生导入。共享表现类 `ProjectileArt` 只负责映射和绘制。

验收：导入无解析／资源错误；原生渲染逐类检查形状、透明边缘、朝向、同屏辨识和缩放；用实际战斗弹体检查五种来源、范围强化与暂停／倍速。复用战斗回归确认数值和清理。实际结果见 [验证记录](../testing/projectiles.md)。
