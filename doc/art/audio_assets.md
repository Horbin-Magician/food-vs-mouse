# 原创音频资产

状态：7 首音乐及 28 个音效已生成，解码、波形与本机重复生成检查通过（2026-09-26）。适用范围：全游戏音乐和事件音效；触发与混音规则见 [全游戏音频](audio.md)。

## 编曲与音色

主题为深夜厨房中轻巧、温暖的器乐：木琴、柔和电钢琴、短拨弦、圆润低音与锅碗般的轻打击。菜单与小铺采用大调和弦及轻摇摆节奏，战斗增加切分低音和鼓点；精英、首领改用小调及更紧密的节奏。旋律、和声、节奏与合成音色均为本项目原创。

音乐使用 16～24 小节的完整段落，并对后半段改变旋律、声部或打击编排。胜败使用 8 小节结尾主题；失败保留温暖音色，使用下行旋律。稳定 ID 与文件名相同，存放于 `assets/audio/music/<id>.ogg`。

音效存放于 `assets/audio/sfx/<id>.wav`，以柔和包络的木质敲击、玻璃冰晶、蒸汽气流、弹拨、锅盖共振、短促厨房碰撞与少量卡通音高滑动区分事件。事件列表以 [全游戏音频](audio.md) 为准，不新增玩法事件。

## 生成与规格

- 源脚本：`tools/generate_audio.py`，固定随机种子；无需网络或游戏运行时音频合成。
- 音乐：44.1 kHz、立体声、Ogg Vorbis；按整小节采样长度生成。为匹配本机 Vorbis 编码器，将总采样数向上对齐至 64，并按实际总长度微调拍长（实际 BPM 见 manifest，与名义值差小于 0.004）。解码无额外补零。超出末尾的乐器衰减与短混响折返至开头，保持循环尾音；不在每圈结尾淡出。
- 音效：44.1 kHz、单声道、16-bit PCM WAV，无循环；头尾包络避免突变。
- 音乐解码峰值控制在约 −6 dBFS，音效峰值约 −4 dBFS；实际游戏响度由音频 Resource 的各事件增益进一步控制。
- `assets/audio/manifest.json` 保存各文件的节拍、小节数、时长、峰值、RMS、SHA-256、原创来源与生成工具版本。

生成环境实际使用本机已有 Python 3.12.14、NumPy 2.3.5、FFmpeg 9.0.1 的原生 Vorbis 编码器（开发机 macOS arm64）。它们仅为开发工具，不加入游戏运行依赖。未引入第三方音频、采样、曲目、外部插件或下载资源；生成音频与乐谱归本项目原创内容，按项目代码／原创资产的整体许可处理，不额外附加第三方素材许可。FFmpeg 和 NumPy 自身许可不作为输出音频的许可。

在具备 NumPy 的 Python 环境执行 `python3 tools/generate_audio.py`；FFmpeg 不在 PATH 时传 `--ffmpeg /path/to/ffmpeg`。生成脚本仅更新已存在音乐导入文件的循环／节拍字段，保留 Godot 创建的 UID 与导入路径；首次生成后仍需 Godot 导入。音乐导入设置为循环，音效不循环。
