状态：已实现；自动回归、实际渲染与窗口鼠标检查见 [UI 验证](../testing/ui.md)。适用：首版「使用体验」里程碑，2026-09-13 全界面优化。玩法与几何沿用 [TODO](../TODO.md) 和 [棋盘布局](perspective.md)。

## 视觉体系

采用现代深夜食堂风格：墨绿背景、奶油白正文、薄荷绿主操作、暖金资源、珊瑚红危险提示。弱化木纹、瓷砖和重复描边，让原创角色与棋盘成为视觉中心。8/12/16/24 像素间距、10–16 像素圆角，统一按钮、悬停、选中、禁用、键盘焦点和提示气泡。中文沿用系统字体回退，无新增外部资源、字体、插件或依赖。

顶部保留资源、最多八卡及锅铲；底部操作栏区分主流程、暂停速度和管理操作，与右侧关卡进度横向同排，具体位置依据 [棋盘布局](perspective.md)。卡牌使用紧凑图文布局，展示上方图像、下方费用和右上星内等级，名称和持有进度放入悬停；不保留底部状态文字，锅铲仅显示图标。选中使用边框及底色，冷却使用覆盖整卡、从上至下消退的阴影；状态与剩余秒数放入悬停提示，非法操作仍有明确原因。

棋盘使用 [棋盘布局](perspective.md#当前规则) 定义的扩大后 7×9 正方形网格；顶部贴边下延、底部贴边位置也以该文档为准。左侧不保留信息卡片；底部左侧用于操作栏。小铺采用居中弹窗，具体规则见下节；右侧食谱与战报面板避开棋盘与入口，展示效果或结果统计，可收起，战斗默认隐藏。底部右侧继续显示真实生成进度，不把满条当成胜利。

## 状态与边界

- UI 只读取状态、请求业务接口。购买、维修、暂停、放置与阶段限制沿用业务校验；禁用操作附说明，不改变费用和规则。
- 提示与详情遵循下文「提示栏与引导移除」；详细单位说明继续放入卡牌悬停。
- 铲除与重开使用统一风格的确认弹窗，明确结果、确认与取消。弹窗打开时棋盘不接收操作。
- 选择、调位、锅铲互斥，右键/Esc 取消。准备、战斗、暂停、胜败均展示明确的阶段与下一步。重开清除残留选择。
- 逻辑分辨率 1280×720，按现有 canvas_items 等比缩放，不引入移动端适配。八卡、长中文效果、售罄、满星、金币不足、食谱为空与十二食谱清单均应保持边界内可用。
